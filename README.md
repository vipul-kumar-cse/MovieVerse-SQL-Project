# 🎬 MovieVerse SQL Project

## 📌 Project Overview
MovieVerse is a SQL-based data analysis project focused on exploring movie data, user ratings, genres, actors, and release years. The project uses SQL queries to answer analytical questions and extract meaningful insights from a movie database.

## 🎯 Project Objectives
- Analyze movie ratings and identify top-rated movies.
- Explore user ratings and movie preferences.
- Analyze movies by genre and release year.
- Examine actor participation in movies.
- Practice SQL querying for real-world data analysis scenarios.

## 🛠️ Tools Used
- SQL
- Relational Database Management System (RDBMS)

## 📊 Business Questions Solved
This project explores the following questions:

1. Which movies have the highest ratings?
2. Which Indian users gave ratings above 9?
3. How many movies belong to each genre?
4. Which actor has appeared in the most movies?
5. What is the average rating given by each user?
6. How can movies be ranked by release year?
7. How can movies be classified based on their release year?
8. How can a “Recommended Movie of the Day” be identified?

## 📂 Project Files
- `Movie_Verse Project.sql` — Contains the SQL queries used for the analysis.
- `README.md` — Project documentation.

## 📚 Key Learnings
- Practiced writing SQL queries to answer analytical questions.
- Explored movie ratings, genres, actors, and release-year data.
- Improved understanding of querying and analyzing structured data.

## 🚀 How to Use
1. Clone or download this repository.
2. Open the SQL file in a compatible SQL environment.
3. Set up the required database and tables.
4. Execute the queries to explore the analysis.

*Note: The database schema and required data must be available before running the queries.*
